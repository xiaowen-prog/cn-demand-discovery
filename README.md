# 中文细分需求挖掘与验证 Skill

帮一到三人的小团队找到真实存在、大厂没占住、做得出来、有人付钱的细分需求，并在写代码之前用最低成本把它证伪或证实。

## 两种模式

- **发掘模式**（默认）：从有人手动卖服务、新规政策、新职业、媒体报道的群体痛点、GitHub 中文小工具、应用商店差评、兴趣圈层等信号源铺开二三十个想法，逐个写出机会、卡点、五项得分和证据，做快速卡位扫描后综合排序，展开前五名。
- **评估模式**：对指定方向做完整需求卡：挖需求信号、需求打分、七项卡位检查（一票否决）、可做性评估、验证方案设计（Mom Test 访谈、手工服务、假门测试、预售）。

## 使用方法

本仓库是 AI Agent Skill，不是独立应用。将仓库作为一个技能文件夹放入支持 `SKILL.md` 的 Agent 的技能目录，或让 Agent 读取 [SKILL.md](SKILL.md) 后执行任务。具体加载方式以所用 Agent 为准。

```text
使用 $cn-demand-discovery，帮我找一批适合一人团队做的 AI 小工具方向，面向国内用户。
```

```text
使用 $cn-demand-discovery，评估「宠物用药提醒小程序」这个方向能不能做。
```

## 文件结构

- `SKILL.md`：两种模式的完整流程、打分规则、卡位检查清单与需求卡模板。
- `agents/openai.yaml`：支持该格式的 Agent 的界面元数据。

搜索小红书、抖音、公众号等平台需要运行环境具备浏览器工具；没有时 Agent 应如实说明，并把搜索关键词交给用户。本 Skill 不使用破解、绕过登录或批量爬虫获取数据。
